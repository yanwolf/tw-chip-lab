# tw-chip-lab 籌碼峰實驗室

台股全市場（上市＋上櫃普通股）籌碼峰回測。第一階段：只掃描與回測，不下單。

## 部署（Coolify）
1. 新建 GitHub repo `tw-chip-lab`，把整包推上去。
2. Coolify 新增服務 → 從 GitHub repo → Build Pack 選 **Dockerfile**。
3. **Persistent Storage**：掛一個 Volume 到 `/data`（SQLite 在這裡，沒掛重啟就全沒了）。
4. 環境變數：
   | 變數 | 說明 |
   |---|---|
   | `APP_PASSWORD` | 登入密碼（建議設） |
   | `AUTO_UPDATE` | `1` = 平日 16:30 後自動補抓當天資料 |
   | `FETCH_INTERVAL` | 請求間隔秒數，預設 `4`，不要調太低 |
5. Port 8000，網域自訂（例如 chip.tzujenlab.com）。

## 使用流程
1. 「資料」頁按「開始抓取」，預設抓三年（約 1.5～2 小時，可中斷續抓）。
2. 抓完到「回測」頁按「執行回測」，全市場約 1～2 分鐘。
3. 看「事件研究」的 **20 日超額報酬** 和 **t 值**：超額為正且 |t| ≥ 2 才值得往下做。
4. 點任一筆交易可看當時的 K 線＋籌碼分布，確認訊號是不是你要的型態。

## 第一次部署要確認的事
- **櫃買中心網址**：上櫃日資料用新版網址，失敗會自動改用舊版。若「資料」頁顯示上櫃全部失敗，把錯誤訊息貼給 Claude 修。
- **證交所封鎖**：回應不是 JSON 通常是請求太快或主機 IP 被擋，程式會等 60／120 秒重試三次，仍失敗就停在那天。

## 模型與限制
- 籌碼分布是用成交量＋換手率**推估**的（通達信 CYQ 做法），不是真實持股。
- 換手率 = 成交股數 ÷ 已發行股數；股本是**目前快照**，有大幅增減資的股票早期換手率會失真。無股本資料的股票改用估計值（結果頁會標示檔數）。
- 價格自動還原除權息、減資（用交易所的「漲跌」反推參考價）。
- 台股換手率低，早期「資料起點」以前的籌碼未知，所以預設暖機 250 個交易日才開始產生訊號：抓三年資料，實際可回測約兩年。
- 下市股票的歷史行情也在每日全市場資料裡，所以沒有倖存者偏差。

## 檔案
- `app/fetch.py` 證交所／櫃買抓取與解析
- `app/chips.py` 還原價、籌碼分布模型
- `app/backtest.py` 訊號、交易、事件研究
- `app/server.py` 網頁與 API（純標準庫）
- `app/static/index.html` 儀表板
- `tests/test_core.py`、`verify.sh` 離線驗證

## 實盤追蹤（「實盤」分頁）
- 每月入金後記錄一筆「入金」，每筆零股成交記錄「成交」。
- 收盤資料更新後自動掃描訊號（參數預設＝回測 #42，可在設定套用其他回測）。
- 「明日動作」列出要賣的持股（停損／移動停利／持有到期，規則跟回測相同）與要買的訊號（股數、限價）。
- 「複製到方舟下單」：明日動作會產生方舟網站「批次貼上」格式（代號,buy/sell,股數,價格,備註），複製後直接貼上送單。
- 對照組：同樣的入金照比例買對照 ETF（預設 00878、00981A 各半，含息還原），直接比較。
- 對照 ETF 的歷史行情用證交所個股月資料自動補齊；之後每日抓取會一併保留。
